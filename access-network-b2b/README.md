# Access Network Business: website mockup

Five-page static mockup of a business-sales website for **Access Network, powered by RA Omega Cable TV Corporation**, aimed at commercial customers in Nueva Ecija: businesses, cooperatives, schools, clinics, resorts, contractors and LGUs. Content comes from the *Access Network Company Profile 2026*. It is the B2B companion to the EU-audience mockup in `../access-network-site/`.

| Page | File | Purpose |
|---|---|---|
| Home | `index.html` | Value proposition, coverage checker, four service lines, industries, delivery process, reasons to buy |
| Connectivity | `connectivity.html` | Business broadband vs private fiber vs cable TV, what to prepare for a quote, core towns |
| Enterprise IT | `enterprise-it.html` | System integration, colocation & DRC, managed support, CCTV, example bundles |
| Fiber & Solar | `projects.html` | Fiber design/laying/splicing, network supplies, solar, staff training, track record, project gallery |
| Get a quote | `quote.html` | Quote / site-survey request form, contact details, next steps, FAQ |

Open `index.html` in a browser. No build step; fonts load from Google Fonts.

## Before launch

Items marked with a dashed **Placeholder** chip need real content: plan table and pricing, support response times and hours, office hours, and project photos.

- The coverage checker is indicative. It treats the five towns named in the profile (San Jose City, Rizal, Llanera, Carranglan, Pantabangan) as the core service area and every other Nueva Ecija town as "project basis".
- The quote form is not connected; submitting shows a notice and sends nothing.
- Industry segments, example bundles and some service details (private fiber links between sites, solar backup for network and CCTV) are extrapolated from the profile's service categories. Confirm they match what you sell.
- No prices, speeds or SLAs are stated anywhere.
